# Getting started on JuniSMP

Five steps, a few minutes, then you're playing.

1. **Install Prism Launcher** — [prismlauncher.org/download](https://prismlauncher.org/download).
   Free, works on Windows/Mac/Linux.
2. **Import the modpack** — in Prism: **Add Instance → Import → From Zip**,
   paste this link in the URL box:
   `https://github.com/0124212/JuniSMP/releases/download/prism-latest/JuniSMP-prism.zip`
   Hit OK and let it download — it's a big pack (100+ mods), give it a
   minute or two.
3. **Get whitelisted** — ping **@kutejuni** with your Minecraft username.
   You can't join until you're added.
4. **Launch & connect** — open the new **JuniSMP** instance in Prism, hit
   **Play**, then in-game: **Multiplayer → Add Server** → `mc.junilab.xyz`.
5. *(Optional)* Turn on the bundled resource pack — it's not enabled by
   default. **Options → Resource Packs → Pixel Perfection Fidelity**.

That's it — you're in.

## First things to do in-game

- Open your inventory and find the new **Skills** tab (Skill
  Proficiencies) — you start leveling the moment you start playing
  normally, no setup needed.
- Build a **Waystone** near your base early. It's the fast-travel system
  for this world and saves a lot of walking once your base isn't close to
  spawn anymore.
- Keep the [mod guide](docs/mod-guide.md) bookmarked for when you run
  into something unfamiliar — covers the mods with real mechanics
  (skills, mining, storage, magic, farming, worldgen) with links to each
  one's own docs.
- Check the [live 3D map](https://map.junilab.xyz) to get your bearings
  or see where people have already built.

## If something's not working

- **Can't connect / not whitelisted** → ping **@kutejuni**.
- **Modpack won't import / mods missing** → re-download from the link in
  step 2, not an old copy — it's rebuilt automatically whenever the pack
  changes, so that link is always the current version.
- **Something in-game is confusing** → check the [mod guide](docs/mod-guide.md)
  first; if it's still not covered, ask in the server chat.
